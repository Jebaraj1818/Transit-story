# The Transit Story — Media Assets

To enable the real client hero background video:
1. Place the client video file here as:
   public/assets/hero-video.mp4

2. (Optional) Place the video poster image here as:
   public/assets/hero-poster.jpg

The hero component automatically detects and uses 'hero-video.mp4' if present.
If the file is absent or cannot be loaded, the site seamlessly displays the curated South Indian editorial photography fallback without any broken video or UI glitch.
